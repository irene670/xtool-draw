# xtool 現場成交幸運輪系統

xTool 多設備現場成交互動抽獎系統。

## 最新架構

開啟網站後會先進入「設備活動選單」，再選擇 O1、X1、F2 等不同設備活動。

每一個活動會獨立保存：
- 設備名稱與活動名稱
- 六個獎品與抽獎機率
- 固定機率／固定獎池設定
- 獎池庫存
- 進行中的成交抽獎
- 成交、抽獎與中獎紀錄

## 工作人員 PIN

- 全新系統預設 PIN：**0000**
- 舊版若仍是原始預設 1688，升級時會自動改為 0000
- 若之前已自行修改其他 PIN，會保留自訂密碼

## 新增活動

活動選單可直接新增設備活動：
1. 建立空白活動
2. 複製既有活動的獎品、機率與模式

複製活動不會複製成交或中獎紀錄。

## 目前抽獎功能

- 賀成交 5 秒提示音
- 六格等分幸運轉盤

- 獎品／機率後台設定
- 中獎結果與活動紀錄
- 閨蜜機大型觸控畫面
